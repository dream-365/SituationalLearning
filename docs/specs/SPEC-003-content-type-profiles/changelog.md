# Changelog: SPEC-003 情景学习 字幕学习报告内容类型分型

## [2026-11-03] - 修正可复现性验收口径

- **修改类型**: Changed
- **影响范围**: 5.3 可靠性与可复现性
- **变更原因**: 代码对照发现报告 HTML 固定包含 `generated_at` 时间戳，两次构建不可能 sha256 完全一致；原验收条件与既有产物格式矛盾。
- **具体内容**: 将 5.3 验收改为“manifest sha256 一致；报告 HTML 除 `generated_at` 外一致”，与 5.1 的时间戳豁免保持一致。

## [2026-11-03] - 补充顶层章节摘要

- **修改类型**: Changed
- **影响范围**: 第 3、4、7 章
- **变更原因**: 评审项声明在顶层章节（而非子小节）时，顶层章节正文为空，评审无法在不引用子小节的情况下给出证据。
- **具体内容**: 在第 3、4、7 章标题下各补一段直接摘要，分别覆盖拓扑/变与不变、数据与接口契约、Status Quo/否决方案/权衡矩阵与最终结论。

## [2026-11-03] - 补充章节摘要以支撑评审证据

- **修改类型**: Changed
- **影响范围**: 第 5 章、第 7 章
- **变更原因**: 独立评审把第 5 章、第 7 章的子小节内容作为证据，但审计按顶层章节正文定位，导致证据找不到。
- **具体内容**: 在第 5 章标题下补一段覆盖 NFR 类别与 [estimated] 标注的摘要；在第 7 章标题下补最终选型与 Goals/架构一致的结论。

## [2026-11-03] - 质量评审意见修复

- **修改类型**: Changed
- **影响范围**: 2.1、5.1-5.5、6.3-6.5
- **变更原因**: 第二轮独立评审发现未实测指标未标 `[estimated]`、NFR 缺少可观测性、冒烟与回滚缺少可观察数字、G5 缺少后续章节落点、Goal 未分类。
- **具体内容**: 为 5.2 的耗时与缓存命中率补 `[estimated]` 与验收方式；新增 5.5 可观测性；为 5.1/5.3/5.4 补验收；6.3 增加观察指标；6.4 改为可观测数字触发条件并给出具体回滚命令；新增 6.5 文档交付；Goal 增加架构/生成/展示/可靠性/可运维分类。

## [2026-11-03] - 质量评审前的结构补全

- **修改类型**: Changed
- **影响范围**: 2.2、3.1、3.4、第 4 章、6.1、6.2、6.4
- **变更原因**: 独立评审发现第 4 章缺少“数据模型 / 接口 / 核心流程 / 异常处理”的显式小节，第 6 章小节名与评审预期不一致，部分证据引述跨节。
- **具体内容**: 补充模块职责、关键选型、数据模型契约、接口协议、关键流程与异常路径；重排第 4 章小节并统一第 6 章小节名；在 2.2 补写“内容类型由 CLI 显式指定”。

## [2026-11-03] - 新增内容类型分型

- **修改类型**: Added
- **影响范围**: G1-G5、4.1 内容类型与 profile、4.2 展示文案契约、4.3 电影生成契约、4.4 缓存与兼容
- **变更原因**: 用户当前同时观看纪录片与剧情电影，现有提示词、章节约束、TTS 语气与报告文案只适用于纪录片；电影字幕会产出论证导向的错误报告。
- **具体内容**: 新增 `documentary` / `movie` 两种内容类型与显式 CLI 参数；电影使用独立提示词、6–12 个场景段落、剧情/台词导向选词与电影文案；纪录片提示词、缓存路径、TTS 缓存键与报告文案保持逐字节兼容；同一字幕双题材发布仍采用最后发布生效。
